# Feature Specification: Collapsible Note Widget

**Feature Branch**: `002-collapsible-note-widget`  
**Created**: 2026年2月13日  
**Status**: Draft  
**Input**: User description: "Webページ上の右下に表示されるメモウィジェットを、畳まれた状態で開始し、クリックすると展開される形式に変更する"

## Clarifications

### Session 2026-02-13

- Q: ページリロード時のウィジェット状態の扱いについて - リロード時に状態を保持するか、デフォルト状態にリセットするか？ → A: リロード時に状態を保持（展開されていた場合は展開状態で表示）
- Q: 展開されたウィジェットのサイズ調整機能について - ユーザーがサイズを変更できるようにするか？ → A: サイズは固定（現在の実装と同じ）
- Q: 畳まれた状態のウィジェットをクリックした時の展開アニメーションの方向について → A: 左上方向に展開（右下から対角線上に）
- Q: 畳まれた状態のウィジェットのデザインについて - 小さなアイコンか、別の形状か？ → A: 縦幅が低い横長バー
- Q: 畳まれた状態のバーに表示するテキストやラベルについて → A: 「PageNotes」というテキストを表示

## User Scenarios & Testing *(mandatory)*

### User Story 1 - Toggle Widget Visibility (Priority: P1)

ユーザーは、必要に応じてメモウィジェットを表示・非表示にできるようにしたいと考えています。Webページを閲覧しているとき、デフォルトでは畳まれた状態のメモウィジェットが右下に小さく表示されており、クリックすることで展開してメモを編集できるようになります。メモが不要な場合は、ウィジェットを閉じてページコンテンツに集中できます。

**Why this priority**: これは機能の中核であり、ユーザーが邪魔にならない方法でメモ機能にアクセスできるようにします。この機能がなければ、常に展開された状態のウィジェットによってページコンテンツが隠れてしまいます。

**Independent Test**: ページをリロードしてメモウィジェットが畳まれた状態で表示されることを確認し、ウィジェットをクリックして展開されること、再度クリックして畳まれることを検証できます。

**Acceptance Scenarios**:

1. **Given** ユーザーがWebページを開いた状態で、**When** ページが読み込まれると、**Then** メモウィジェットは右下に畳まれた状態（最小化された状態）で表示される
2. **Given** メモウィジェットが畳まれた状態で、**When** ユーザーがウィジェットをクリックすると、**Then** ウィジェットが展開され、メモの内容が表示される
3. **Given** メモウィジェットが展開された状態で、**When** ユーザーがウィジェットの閉じるボタンまたは畳むボタンをクリックすると、**Then** ウィジェットが畳まれた状態に戻る
4. **Given** ユーザーがメモウィジェットを展開し、メモを編集している状態で、**When** ウィジェットを畳むと、**Then** 編集内容は保存され、次回展開時に表示される

---

### User Story 2 - State Persistence Across Pages (Priority: P2)

ユーザーは、同じWebサイト内でページを移動しても、メモウィジェットの表示状態（展開/畳まれた状態）が保持されることを期待します。あるページでウィジェットを展開した場合、同じドメイン内の別のページに移動しても展開された状態が維持されます。

**Why this priority**: ユーザーエクスペリエンスを向上させる重要な機能ですが、基本的なトグル機能（P1）がなければ意味がありません。ユーザーが毎回ウィジェットの状態を設定し直す必要がなくなります。

**Independent Test**: ウィジェットを展開した状態で同じドメインの別のページに移動し、展開された状態が保持されることを確認できます。

**Acceptance Scenarios**:

1. **Given** ユーザーがあるページでメモウィジェットを展開している状態で、**When** 同じドメイン内の別のページに移動すると、**Then** 新しいページでもウィジェットは展開された状態で表示される
2. **Given** ユーザーがメモウィジェットを畳んでいる状態で、**When** 同じドメイン内の別のページに移動すると、**Then** 新しいページでもウィジェットは畳まれた状態で表示される
3. **Given** ユーザーが異なるドメインのWebサイトに移動した状態で、**When** ページが読み込まれると、**Then** メモウィジェットはデフォルトの畳まれた状態で表示される

---

### User Story 3 - Visual Indicator for Collapsed State (Priority: P3)

ユーザーは、メモウィジェットが畳まれている状態でも、メモ機能が利用可能であることを視覚的に認識できる必要があります。畳まれた状態のウィジェットには、クリック可能なアイコンやボタンが表示され、ユーザーがメモ機能の存在に気づき、必要に応じてアクセスできるようにします。

**Why this priority**: ユーザビリティの向上に貢献しますが、基本的な機能（P1とP2）が実装された後に追加できる視覚的な改善です。

**Independent Test**: 畳まれた状態のウィジェットが明確に視認でき、ホバー時に適切なフィードバック（色の変化、ツールチップなど）が表示されることを確認できます。

**Acceptance Scenarios**:

1. **Given** メモウィジェットが畳まれた状態で、**When** ユーザーが画面を見ると、**Then** 右下にメモアイコンまたはボタンが明確に表示される
2. **Given** メモウィジェットが畳まれた状態で、**When** ユーザーがアイコンにマウスホバーすると、**Then** 視覚的なフィードバック（色の変化、影の表示など）が表示される
3. **Given** メモウィジェットが畳まれた状態で、**When** ユーザーがアイコンにマウスホバーすると、**Then** 「メモを開く」などの説明文がツールチップとして表示される

---

### Edge Cases

- ウィジェットが展開されている状態でページをリロードした場合、展開状態が保持され、リロード後も展開された状態で表示される
- ウィジェットが展開されている状態で、別のブラウザタブから同じページを開いた場合、ウィジェットの状態は同期されるか？
- ウィジェットのアニメーション（展開・畳む動作）が非常に遅いデバイスで実行された場合、ユーザーエクスペリエンスはどうなるか？
- ウィジェットが展開されている状態で、画面サイズが非常に小さい（モバイルデバイスなど）場合、ウィジェットがページコンテンツを完全に覆ってしまう可能性はあるか？

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: システムは、ページ読み込み時にメモウィジェットをデフォルトで畳まれた状態で表示しなければならない
- **FR-002**: システムは、ユーザーが畳まれた状態のウィジェットをクリックすると、ウィジェットを展開してメモの内容を表示しなければならない
- **FR-003**: システムは、ユーザーが展開されたウィジェットの閉じるボタンまたは畳むボタンをクリックすると、ウィジェットを畳まれた状態に戻さなければならない
- **FR-004**: システムは、ウィジェットの展開・畳む動作を視覚的に滑らかなアニメーションで表示しなければならない（展開時は右下から左上方向に、畳む時は左上から右下方向に）
- **FR-005**: システムは、ウィジェットの現在の状態（展開/畳まれた）を永続化し、同じドメイン内でページを移動しても状態を保持しなければならない
- **FR-006**: システムは、畳まれた状態のウィジェットを画面の右下に固定位置で表示し、ページのスクロールに影響されないようにしなければならない
- **FR-007**: システムは、展開されたウィジェットが既存のメモ表示機能（テキストエリア、保存機能など）をすべて保持しなければならない
- **FR-008**: システムは、畳まれた状態のウィジェットを縦幅が低い横長のバー状のUIとして表示し、「PageNotes」というテキストラベルを含め、クリック可能であることを視覚的に示さなければならない
- **FR-009**: システムは、ページリロード時にウィジェットの展開状態を保持し、リロード前の状態を復元しなければならない

### Key Entities

このフィーチャーは既存のメモ機能を拡張するもので、新しいデータエンティティは導入しません。既存の以下のエンティティを使用します：

- **Note**: Webページに関連付けられたメモデータ（URL、タイトル、テキストコンテンツ、タイムスタンプ）
- **Widget State**: ウィジェットの表示状態を保持する情報（展開/畳まれた、ドメインごとの設定）

## Success Criteria *(mandatory)*

### Measurable Outcomes

- **SC-001**: ページ読み込み時に、メモウィジェットが畳まれた状態で100%の確率で表示される
- **SC-002**: ユーザーがウィジェットをクリックしてから展開されるまでの時間が0.3秒以内である
- **SC-003**: ウィジェットの展開・畳む操作が、既存のメモ編集機能に影響を与えず、すべての機能が正常に動作する
- **SC-004**: ウィジェットの状態がドメインごとに正確に保持され、ページ移動後も95%以上の確率で正しい状態が復元される
- **SC-005**: ユーザーが畳まれた状態のウィジェットを見つけて、展開する操作を1回目の試行で完了できる割合が90%以上である
- **SC-006**: ウィジェットのアニメーションが滑らかであり、フレームレートが30fps以上を維持する

## Assumptions

- ユーザーは既存のメモ拡張機能を使用しており、基本的なメモ作成・編集機能が実装されている
- ウィジェットの状態は、ブラウザのローカルストレージまたは拡張機能のストレージを使用して永続化される
- デフォルトの畳まれた状態は、すべてのユーザーにとって望ましい初期状態である
- ウィジェットのアニメーションは、CSS transitionまたはアニメーションを使用して実装される
- 畳まれた状態のウィジェットは、縦幅が低い横長のバー状のUIとして右下に表示され、「PageNotes」というテキストラベルが含まれる（幅は適度に確保され、極端に短くする必要はない）
- 展開されたウィジェットのサイズは固定であり、現在の実装と同じサイズを維持する(ユーザーによるサイズ調整機能は含まない)
